# Mindware_Prototip

BLE 5.1 hibrit konumlama (RSSI + AoA) • Dijital İkiz • .NET Core 8 mikroservisler • SignalR • SCOR KPI analitiği

Bu depo, Mindware prototip uygulamasının kaynak kodunu, mimarisini ve yerel/uzak (cloud) çalıştırma talimatlarını içerir. Proje; beacon tabanlı iç mekân konumlandırma, gerçek‑zamanlı operasyon takibi ve SCOR modeline dayalı karar destek analitiğini tek bir mimaride birleştirir.
